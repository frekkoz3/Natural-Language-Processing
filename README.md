# Natural Language Processing

This repository contains the course material (and practical tutorials) for the academic course of **Natural Language Processing** held by professors A. Ansuini and D. Doimo @ University of Studies of Trieste.

The course will follow [**Speech and Language Processing**](https://web.stanford.edu/~jurafsky/slp3/) by *Dan Jurafsky and James H. Martin*.

The repository is updated on a weekly basis.
